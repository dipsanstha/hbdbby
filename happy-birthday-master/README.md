# Happy Birthday

A responsive birthday surprise made with HTML, CSS, and JavaScript.

Open `index.html` in a browser and follow the prompts to make a wish, open the letter, browse the photos in the memory album, and reveal the rose. The video in `photos/` plays muted and loops as the page background.

To personalize the recipient's name, add it as a URL parameter, for example:

```text
index.html?name=Maya
```

The bundled photos in `photos/` appear in the memory album. Additional photos selected with **Add your photos** are previewed locally in the current page; they are not uploaded or saved after the page is closed or refreshed.
